Mulai dari domain gangguan yang benar, bukan dari satu upload box yang sama.

Jaringan transmisi dan transformator punya filosofi analisis yang berbeda. Pilih jalur yang sesuai supaya input, hasil, dan evidence yang diminta selaras dengan cara engineer membaca gangguan di lapangan.

Distance / 21 87L 87T OCR HV / LV REF / GFR / SBEF

Prinsip Kerja

  • Jaringan: cepat ke pola arus-tegangan, AR, dan cause classification.
  • Trafo: mulai dari relay role, event meaning, lalu origin fault dan selectivity.
  • Jika evidence belum cukup, sistem seharusnya minta relay tambahan, bukan memaksa final cause.
Jaringan Transmisi
Input Jaringan
Dipakai untuk rele jarak, DFR jaringan, dan analisis cepat penyebab seperti petir, layang-layang, hewan, benda asing, pohon, atau konduktor/tower.
Satu pasangan file `.cfg + .dat`
Cocok untuk distance relay, DFR eksternal, atau screening cepat gangguan jaringan
Hasil fokus ke transien/permanen dan cause ranking
Masuk ke Input Jaringan Pilih dari Raw Data
Transformator
Input Trafo
Dipakai untuk 87T dan juga relay pendukung seperti OCR HV, OCR LV, REF, GFR HV, atau SBEF. Sistem membedakan quick local analysis dan coordinated multi-relay analysis.
Mulai dari relay yang tersedia sekarang
Cocok untuk localization, selectivity review, dan event interpretation
Jika file awal hanya OCR LV, hasil diposisikan sebagai partial evidence, bukan final transformer cause
Masuk ke Input Trafo Lihat Riwayat 87T

Kapan Pilih Jaringan

Jika fokus utamanya adalah penyebab gangguan penghantar, auto-reclose, waveform line current, dan klasifikasi petir/hewan/benda asing.

Kapan Pilih Trafo

Jika event melibatkan transformator, relay sisi HV/LV, 87T, atau Anda ingin menilai apakah origin fault sebenarnya internal, distribusi, atau hanya backup trip.

Kaidah Umum

Untuk domain trafo, relay coordination tetap menjadi sumber kebenaran utama untuk localization. ML hanya membantu membaca waveform lokal ketika koordinasi belum menjawab cukup.
